# AGENTS.md

## Проєкт

Це навчальна копія публічного сайту Фундації Лятошинського для воркшопу spec-driven BA. Сайт знайомить відвідувача зі спадщиною композитора Бориса Лятошинського: життєпис, творчість, дослідження, архів, новини, а також місію фундації, співпрацю і способи підтримки. Застосунок на Next.js; локаль за замовчуванням — `uk`, тож основні адреси мають вигляд `/uk/...`.

| Шлях | Бізнес-призначення |

## Конвенції

- Код пишеться на TypeScript.
- Експортуйте іменованими експортами, без `export default`. Виняток — файли маршрутів Next.js (`page.tsx`, `layout.tsx`, `route.ts`): фреймворк вимагає default export.
- Основна мова інтерфейсу і текстів — українська (`uk`). Англійська (`en`) — друга локаль.

## Навчальний репозиторій

Це не продакшен. Окрема MongoDB і зовнішні сервіси не потрібні: під час `npm run dev` піднімається in-memory база з демо-даними. База скидається при кожному запуску і зникає після зупинки застосунку. Зміни даних між сесіями не зберігаються.
З бібліотекою MongoDB на ПК з Windows можливі проблеми. Для їх вирішення потрібно переінсталювати MongoDB з новішою версією.
